# GodmorgonKebab

## Company Description

We are a company that sells pizzas, kebabs, salad and drinks. Our main product is made with attention to detail and shipped directly to your home. Our target audience is young adults. We want to convey a sense of charm, while at the same time being professional.

## Job Description

You must create a website that will mainly make it easy to contact the company. Besides the landing page, the website will need a contact page, menu page and an about page. The young adults would prefer an easy to use, and charming design. We would like you to use the brand color, which is light red, but also include playful colors.
